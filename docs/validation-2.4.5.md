# 2.4.5 validation scope

## English

This release follows a fresh local installation after Steam verified 695 game files. The loader, Core and two separately installed character packs accounted for 108 imported files, each checked against the intended SHA256. The tested Core had 60 GameFiles. The final release preserves those 60 files byte-for-byte and only finalizes documentation / metadata. A cold launch and save load completed, and the user confirmed that the F6 panel worked. The experiment that changed F11 fullscreen behavior is absent.

This is not a claim that a full character, physics, battle, cutscene, controller, teleport or uninstall regression was rerun for 2.4.5. Existing earlier acceptance remains scoped to its tested installation. This round did not add a new gameplay demonstration or a performance benchmark. Vortex remains unverified. Final public ZIP and downloaded release assets are checked independently during publication.

## 简体中文

本轮先由Steam校验695个游戏文件，再全新导入加载器、Core和两个单独角色包，共108个文件逐一核对SHA256。实测Core含60个GameFiles，最终发行保留这60个文件原始字节，只整理文档和元数据。冷启动、读档成功，用户确认F6面板生效；F11全屏兼容试验已移除。

本轮没有重新遍历角色、物理、战斗、过场、手柄、传送或卸载的完整回归，也没有新增游戏演示或帧率测试。此前验收仍限于其当时的测试环境，Vortex尚未验证。公开ZIP及实际下载附件将在发布时另行核对。
